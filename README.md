# Web Programming Lab - ByteShop Electronics

A simple HTML exercise that presents a fictional electronics shop.

## Page features
- Store branding and a local logo image
- Audio element with a sample MP3 file
- Navigation links to page sections
- Tables for laptops and accessories
- Sample delivery and order form sections

## Files
- `ex1.html` - main page
- `logo.png` - store logo
- `jingle.mp3` - example audio asset

## Run
Open `ex1.html` in your browser with the other files in the same folder. No PHP or database is needed.

This is an early HTML learning exercise, not an online checkout system.
